## 📖 Overview
PlacePrep AI helps students combat placement anxiety by providing a centralized dashboard for their interview preparation. The app simulates a mobile interface where users can track their upcoming interview countdown, monitor their daily DSA goals, and take AI-simulated mock interviews with instant feedback. 

This project was built as part of the **Handshake AI Skills Studio x Figma Challenge** using ChatGPT to rapidly generate the UI/UX and functional code.

## ✨ Key Features
- **Interview Countdown:** A visual timer displaying the days left until the target interview (T-Minus).
- **DSA & Core Subject Tracker:** A clean checklist interface to track daily revision topics (e.g., Arrays & Strings, DBMS, OS).
- **AI Mock Interview Interface:** A simulated chat UI where the app asks a technical question (e.g., "Explain the difference between a process and a thread").
- **Instant Feedback Screen:** A results page showing a performance score (e.g., 8/10) and areas for improvement.
- **Premium UI/UX:** A modern, dark-themed aesthetic with neon green accents and smooth screen transitions, mimicking a real production-ready mobile app.
